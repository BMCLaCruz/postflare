Postflare

Privacy Policy

Last updated: October 12, 2026

Postflare is open-source, self-hosted social media scheduling software. This Postflare instance is run by its operator, who decides who may use it. This policy describes what this instance does with the data of the people who use it ("users").

What we collect

When a user connects a social media account (for example TikTok, Instagram or YouTube), Postflare stores the access tokens the platform issues, together with basic profile information (account id, display name, username and avatar), the posts and media the user schedules, and performance metrics of those posts and accounts (such as views, likes, comments and follower counts). For sign-in it stores the user's name, email address and a hashed password.

How it is used

This data is used only to publish the user's scheduled posts to the user's connected accounts, show their status and performance to the user and the members of their workspace, and refresh access tokens. It is not sold, shared with third parties, or used for advertising.

Google and YouTube data

When a user connects a YouTube channel, Postflare uses the YouTube Data API only to upload videos the user chooses to the user's own channel, set their title, description, privacy, playlist and thumbnail, and post a first comment. It reads the list of the user's channels, playlists and video categories to offer these choices, and the view, like and comment counts of videos published through Postflare and the channel's subscriber and video counts to show the user their performance. Postflare's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not sold, shared with third parties, used for advertising, or used to train AI models. Access can be revoked at any time at myaccount.google.com/permissions.

Storage and security

Data is stored on Cloudflare infrastructure (Workers, D1 and R2). Access tokens are encrypted at rest. Media files are kept until the user deletes them.

Deleting data

Disconnecting an account in Postflare deletes its stored tokens and profile data. You can also revoke Postflare's access at any time from the connected platform's own settings (for TikTok: Settings and privacy → Security → Manage app permissions).

Contact

For questions about this instance or to have your data deleted, contact its operator.
